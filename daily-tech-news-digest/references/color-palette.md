# Terminal Dark Palette

Fixed colors for the digest email. Keep the SKILL.md layout and this file consistent.

## Base

| Use | Hex |
|---|---|
| Page background (outside) | `#05070a` |
| Content container | `#0d1117` |
| Card and block background | `#0a0e14` |
| Card border | `#21262d` |
| Section divider | `#1f2733` |
| Table header row | `#161b22` |

## Text

| Use | Hex |
|---|---|
| Headline, emphasis | `#e6edf3` |
| Body (Top 3 summary) | `#adb5c0` |
| Body (sector item summary) | `#8b949e` |
| Meta (source, date) | `#5c6673` |
| Lighter meta | `#4d5566`, `#3d4552` |
| Run status text | `#5ee0c0` |

## Sector colors

| Sector | Hex | Note |
|---|---|---|
| Enterprise Software | `#7ee787` | green |
| Semiconductors | `#79c0ff` | blue |
| Cloud Infrastructure | `#d2a8ff` | violet |
| Energy | `#ffa657` | amber |
| Health Tech | `#39c5cf` | cyan. Keep it distinct from the green used for Enterprise Software |

## Accent

| Use | Hex |
|---|---|
| Insight label prefix | `#e3b341` |
| Funding amount column (fixed for all rows) | `#7ee787` |

## Why this palette

- A dark background follows the convention of data terminals and suits an analytical tone.
- Sector colors are muted so five of them can sit on a dark page without eye strain, and stay distinguishable at a glance.
- The amount column uses one fixed color so the eye scans a single column for deal size. Using sector colors there would slow scanning.
- If you add or change a sector, choose a color that differs clearly from the existing ones.
